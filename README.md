# GreenMood
For Your Mind

The **"For Your Mind"** section is created to replace the traditional "news" concept.

Rather than delivering real-world news, this section offers:
- Gentle reminders  
- Short self-care tips  
- Mindfulness-focused content  

->All designed to create a more positive and relaxing digital space.

Design Approach:
- Soft green color palette inspired by nature  
- Minimal and clean layout  
- Smooth and calming visual hierarchy  
- Focus on readability and spacing
