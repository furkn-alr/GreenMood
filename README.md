# GreenMood
A nature-inspired, calm and aesthetic web theme.
Green Mood is designed to provide a peaceful user experience with a clean and visually appealing interface.

Features
-Nature-inspired theme
-Soft color palette
-Responsive layout
-Lightweight and fast

Techs Used
-HTML
-CSS
-JavaScript
